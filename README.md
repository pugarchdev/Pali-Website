# Pali Photography — Visual Storytelling & Heirloom Imagery

> *"Every love story deserves a beautiful frame."*

Official web application for **Pali Photography** by **Vivek Pali**, a professional wedding, portrait, and landscape photographer specializing in documentary-led storytelling, candid emotion, and heirloom visual archives.

---

## 📍 Locations & Service Territories

Pali Photography is based in the United Kingdom, delivering bespoke photography commissions across Scotland, the UK, and international destinations:

- **Scotland Primary Hubs**:
  - **Edinburgh** (Old Town, historic estates, royal botanic gardens, and urban architecture)
  - **Glasgow** (Heritage halls, West End, contemporary venues, and cathedral districts)
  - **Scottish Highlands & Wild Horizons** (Glencoe, Isle of Skye, Cairngorms, Loch Lomond, and rugged coastal vistas)
- **UK-Wide Coverage**: Available for weddings, private celebrations, and portrait commissions throughout England, Wales, and Northern Ireland.
- **Destination & Worldwide Travel**: Dedicated destination wedding coverage across Europe and worldwide.

## 🛠️ Technology Stack

- **Framework**: [Next.js 16](https://nextjs.org/) (App Router, Turbopack, React 19)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **3D Graphics**: [Three.js](https://threejs.org/) (Custom WebGL 3D vintage camera optics and interactive photography scene)
- **Animation**: [Framer Motion](https://www.framer.com/motion/) & [GSAP (GreenSock)](https://gsap.com/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **SEO & Metadata**: JSON-LD Structured Data, OpenGraph social cards, dynamic sitemaps, and semantic HTML5

## 🚀 Getting Started

### Prerequisites

- Node.js 18.18+ or Node.js 20+
- npm (or pnpm / yarn)

### Installation

1. Clone the repository:
   ```bash
   git clone <repository-url>
   cd Pali-Website
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run the development server:
   ```bash
   npm run dev
   ```

4. Open [http://localhost:3000](http://localhost:3000) in your browser.
